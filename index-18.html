FEATURES

Einfach, clean und direkt im Chat.

◈

Fake Balance

Setze einen beliebigen Betrag, der nur lokal für dich gespeichert und angezeigt wird.

💸

FakePayments

Aktiviere FakePayments und nutze danach den normalen /pay Name Betrag-Befehl.

⚡

Client-only

Die Mod arbeitet auf deinem Client. Sie verändert kein echtes Server-Guthaben.

🔒

Manuell aus

FakePayments bleibt aktiv, bis du es mit dem Off-Befehl wieder deaktivierst.

BEFEHLE

Alles über den Chat.

/fakebalance 1000000Fake-Guthaben setzen
/fakebalance statusStatus und Guthaben anzeigen
/fakebalance offFakeBalance deaktivieren
/fakebalance fakepayments onFakePayments aktivieren
/pay Max Mustermann 10000Wird bei aktivem FakePayments nur lokal simuliert
/fakebalance fakepayments offFakePayments manuell deaktivieren

INSTALLATION

In wenigen Schritten startklar.

  1. Fabric 1.21.11 installieren.
    Starte Minecraft Java einmal mit deinem Fabric-Profil.
  2. Die JAR herunterladen.
    Nutze den Download-Button auf dieser Seite.
  3. JAR in den mods-Ordner legen.
    Windows: %appdata%\.minecraft\mods
  4. Minecraft starten.
    Die Mod ist clientseitig. Für Fabric-Mods kann zusätzlich die passende Fabric API erforderlich sein.
Wichtig: ZackMC FakeBalance ist ein inoffizielles Community-Projekt. FakeBalance und FakePayments verändern kein echtes Guthaben und führen keine echte Zahlungs-Transaktion aus. Nicht offiziell mit Mojang, Microsoft oder DonutSMP verbunden.
