FEATURES

Was kann die Mod?

💰 FakeBalance

Setze einen Betrag, der nur lokal angezeigt wird.

💸 FakePayments

Simuliere /pay Name Betrag nur auf deinem Client.

👁️ Unauffällig

Keine permanente zusätzliche Mod-Anzeige.

🛡️ Client-only

Kein echtes Guthaben und keine echte Zahlung werden verändert.

BEFEHLE

Alles über den Chat.

/fakebalance 1000000Fake-Guthaben setzen
/fakebalance offFake-Anzeige deaktivieren
/fakebalance statusStatus anzeigen
/fakebalance fakepayments onFakePayments aktivieren
/pay Max Mustermann 10000Fake-Zahlung lokal simulieren
